# TG Bot "Твой психолог" 🧠

**Telegram-бот для психологической поддержки и ведения дневника эмоций.**

Этот бот создан для того, чтобы помочь пользователям лучше понимать свои эмоции, отслеживать настроение и получать базовые психологические рекомендации в формате переписки. Бот выступает в роли "эмоционального компаньона" и не заменяет профессиональную терапию.

## Возможности ✨

*   **Библиотека техник:** Коллекция простых упражнений (дыхательные практики, заземление) для снижения тревожности.
*   **Безопасное общение:** Бот сохраняет анонимность и не передает данные третьим лицам.
*   **Дружелюбие:** Бот дружелюбно общается и помогает справиться с трудной ситуацией.

## Технологии 🛠️

*   **Язык:** Python 3.14+
*   **Фреймворк:** [Aiogram 3.x]
*   **База данных:** PostgreSQL
*   **Асинхронность:** asyncio
